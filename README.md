## Deutsch

Du wolltest schon immer ein Buch schreiben, hast aber den Aufwand drumherum gescheut? Dann geht es Dir wie mir. Aber ich habe mir ein Werkzeug zur Erstellung meiner Bücher gebaut, das Du gerne nutzen kannst:

👉 **https://iSunnyTT.github.io**

SunnyBooks ist ein Editor zum Erstellen und Pflegen von Büchern, kostenlos und ohne Installation.

- **Plattformunabhängig:** Läuft im Browser auf Windows, Android, Linux und mehr. Schreibe am Smartphone, Tablet oder PC, auch im Wechsel und unterwegs.
- **WYSIWYG:** Du bearbeitest die Seite direkt im Buch und siehst jede Änderung sofort, ohne Moduswechsel.
- **HTML-Modus:** Per Umschalter bearbeitest Du den HTML-Code direkt und kannst so Funktionen nutzen, die die Oberfläche nicht bietet.
- **Schutz:** Ein kryptographischer Hashwert schützt Dein Buch vor unbefugten Änderungen, der Zugriff ist passwortgeschützt. (Kein Schutzverfahren bietet absolute Sicherheit.)
- **Smarte Funktionen:** Blättern, Zoomen, Vorlesen, Hintergrund-Fading und Sprachumschaltung DE/EN sind fest eingebaut. Kein universelles Layout-Werkzeug, sondern KISS („Keep it simple, stupid"): einfach zu bedienen, innerhalb eines definierten Funktionsumfangs.
- **Herzensprojekt:** Nicht-kommerziell, als Hobby, aber mit professionellem Anspruch, für alle, die bisher den Aufwand gescheut haben, ein Buch zu machen.

## English

Have you always wanted to write a book, but shied away from all the work around it? Then you're in the same boat as me. I built myself a tool for creating my books, and you're welcome to use it:

👉 **https://iSunnyTT.github.io**

SunnyBooks is an editor for creating and maintaining books, free of charge and with no installation.

- **Platform-independent:** Runs in the browser on Windows, Android, Linux and more. Write on your smartphone, tablet or PC, switch between them, and work on your book on the go.
- **WYSIWYG:** Edit the page right inside the book and see every change instantly, with no switching between modes.
- **HTML mode:** Switch to HTML to edit the code directly and use features the interface doesn't offer.
- **Protection:** A cryptographic hash protects your book against unauthorized changes, and access is password-protected. (No protection method offers absolute security, though.)
- **Smart features:** Page turning, zoom, read-aloud, background fading and DE/EN language switching are built in. Not a universal layout tool, but KISS ("Keep it simple, stupid"): easy to use within a defined set of features.
- **Passion project:** Non-commercial, a hobby, but with a professional standard, for everyone who has so far shied away from the effort of making a book.
